# Shelf-to-Shop

Small Indian sellers sell on Instagram and WhatsApp but rarely have a catalog, because typing products in one
by one takes hours. Shelf-to-Shop turns a 30–60 second phone video of the shelf, with the seller saying prices
aloud ("ye neela wala 1200, cotton wala 850"), into:

- a mobile catalog page with an "Order on WhatsApp" button for each product,
- a Meta catalog feed CSV to upload once to Commerce Manager,
- a zip of clean product photos.

Status: early build. The full README (quickstart, architecture, eval results, security summary) lands by
Nov 4, 2026. Progress is tracked in [PROGRESS.md](PROGRESS.md).
